# Gestor de Tareas



## Estructura de `index.html`

El archivo `index.html` cuenta con la siguiente estructura básica de contenido:

- **Encabezado principal (`<h1>`):** Ubicado en la parte superior del documento, funciona como el título principal de la aplicación.
- **Lista de tareas (`<ul>` y `<li>`):** Situada justo debajo del encabezado, contiene un listado no ordenado con los elementos de prueba iniciales del proyecto.
